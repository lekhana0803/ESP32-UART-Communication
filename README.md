# ESP32-UART-Communication
Inter-MCU UART communication using ESP32 microcontrollers.

Project Overview: This project demonstrates serial communication between two ESP32 microcontrollers using the UART protocol.

Objective: To establish reliable data communication between two microcontrollers and understand UART transmission and reception.

Hardware Components:2 × ESP32 development boards, Breadboard, Jumper wires, LEDs and resistors, PicoScope (for signal observation)

Communication Protocol:UART, TX and RX communication, Serial data transmission and reception

Working Principle: One ESP32 acts as the transmitter and the other as the receiver. Data is transmitted through UART, and the receiving microcontroller processes the incoming data.

Tools Used: Arduino IDE, ESP32, PicoScope
